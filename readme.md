# Understanding AI

A structured collection of notes, explanations, roadmaps, and deep dives covering Artificial Intelligence, Machine Learning, Deep Learning, Generative AI, Large Language Models (LLMs), RAG, AI Agents, Computer Science fundamentals, and modern software engineering.

This repository documents my learning journey from first principles to advanced AI systems. The goal is to build a strong understanding of how modern computing and AI technologies work, not just how to use them.

Topics include:

* Artificial Intelligence (AI)
* Machine Learning (ML)
* Deep Learning (DL)
* Neural Networks
* Computer Vision
* Natural Language Processing (NLP)
* Generative AI
* Large Language Models (LLMs)
* Embeddings & Vector Databases
* Retrieval-Augmented Generation (RAG)
* AI Agents
* System Design
* Cloud & DevOps
* Software Engineering Fundamentals

This repository is maintained as a public knowledge base for continuous learning, revision, and sharing insights with the developer community.
